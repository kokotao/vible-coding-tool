# 网页管理台前端实现蓝图

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `vible-coding-Tool` 补齐首版网页管理台，使其承担“辅助信息面 + 轻操作面”的角色，并与飞书 / QQ 机器人主交互链路配合工作。

**Architecture:** 前端以综合总览首页为主，围绕 `任务 / 会话 / 风控 / 连接中心` 四条主线展开。详情页默认以任务详情为主，配置编辑统一走首页右侧连接中心抽屉，避免把首页做成重型设置后台。

**Tech Stack:** 建议使用 `React + Vite + TypeScript` 或在现有 Node 服务中静态托管单页应用；接口优先复用当前后端网关 API，并补少量管理台专用聚合接口。

---

## 页面清单

### 1. 首页 `/`

定位：综合总览页，也是管理台主入口

核心区块：

- 顶部指标卡
  - `runningTaskCount`
  - `pendingRiskCount`
  - `activeSessionCount`
  - `failedTaskCountToday`
- 中间上半区：任务时间线流
- 中间下半区：最近活跃会话简洁列表
- 右侧上半区：风险待确认卡片列表
- 右侧下半区：连接中心

首页轻操作：

- 停止任务
- 补做确认
- 重试通知
- 重新测试连接

### 2. 任务详情页 `/tasks/:taskId`

定位：默认详情入口，围绕任务做追踪和排障

核心区块：

- 任务摘要
- 消息时间线
- 风控记录
- 审计日志

展示规则：

- 消息时间线默认摘要显示
- 支持展开原始消息内容
- 标题展示 `taskTitle` 优先，`sessionId` 次之

### 3. 会话详情页 `/sessions/:sessionId`

定位：会话级视角，补充查看历史执行上下文

核心区块：

- 会话摘要
- 最近任务列表
- 会话消息时间线
- 绑定信息

说明：

- 会话详情是辅助视图
- 若从任务详情跳入，可保留返回上下文

### 4. 连接中心抽屉

触发位置：

- 首页右侧连接中心点击 `编辑配置`
- 首版不单独拆独立页面，优先做抽屉

抽屉顶部 Tab：

- `连接`
- `风控`
- `模板`
- `绑定`

各 Tab 范围：

- `连接`
  - `App ID`
  - `App Secret`
  - 接入模式
  - 测试连接
  - 保存
  - 事件订阅状态
  - 权限检查
  - 回调地址
  - 最近一次联调结果
- `风控`
  - 高风险关键词
  - 确认开关
  - 确认超时
  - 补做确认入口
- `模板`
  - 任务开始文案
  - 任务成功文案
  - 任务失败文案
  - 待确认文案
- `绑定`
  - 默认群 / 频道
  - `session` 前缀规则

## 路由结构

建议首版前端路由：

- `/`
  - 首页总览
- `/tasks/:taskId`
  - 任务详情
- `/sessions/:sessionId`
  - 会话详情

说明：

- 连接中心走抽屉，不占独立路由
- 首页中的任务时间线与会话列表都可作为详情入口
- 默认详情组织以任务详情为主，会话详情为辅

## 后端接口草案

### 首页聚合接口

- `GET /api/dashboard/summary`
  - 返回指标卡、任务时间线、活跃会话、待确认风险、连接中心摘要

建议返回：

```json
{
  "summary": {},
  "taskTimeline": [],
  "activeSessions": [],
  "pendingRisks": [],
  "connectors": []
}
```

### 任务详情接口

- `GET /api/tasks/:taskId/detail`
  - 返回任务摘要、消息时间线、风控记录、审计日志

### 会话详情接口

- `GET /api/sessions/:sessionId/detail`
  - 返回会话摘要、最近任务、消息时间线、绑定信息

### 连接中心接口

- `GET /api/connectors/summary`
- `GET /api/connectors/:platform/config`
- `PUT /api/connectors/:platform/config`
- `POST /api/connectors/:platform/test`

### 轻操作接口

- `POST /api/tasks/:taskId/stop`
- `POST /api/tasks/:taskId/retry-notify`
- `POST /api/risk/:taskId/confirm`
- `POST /api/risk/:taskId/reject`

## 关键展示与交互规则

- 列表展示优先级：`taskTitle` 优先，`sessionId` 次之
- 首页风险确认支持卡片内直接操作，但机器人消息仍为主确认入口
- 首页连接中心为操作型，不只是状态展示
- 连接配置采用全局单配置，不做多配置切换
- `session` 首版按机器人类型前缀，例如 `feishu-codex-0001`
