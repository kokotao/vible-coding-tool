## 风险与回滚

- 风险：混淆可能导致边缘运行时异常（尤其在 PROTECT_LEVEL=strong）。
- 回滚：
  1. 临时回滚：发布时设置 PROTECT_ENABLED=false。
  2. 永久回滚：将 prepack 恢复为不调用 uild:protect 与 erify:runtime 的旧链路。
