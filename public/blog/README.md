# 灵犀桥 Blog Landing

这个目录放灵犀桥宣传页的静态落地页资源。

## 内容

- `index.html`：博客/宣传页入口
- `blog.css`：页面样式
- `assets/icons/`：SVG 图标素材
- `assets/images/`：透明背景图片与背景切图

## 访问方式

启动服务后访问：

- `http://127.0.0.1:3000/blog/`

## 说明

- 页面基于你提供的设计图做 1:1 风格还原
- 所有可复用图标都拆成了单独的 SVG 文件
- Logo 透明 PNG 已放到 `assets/images/brand-transparent.png`
